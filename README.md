# Portfolio

My personal portfolio built with React, TypeScript, and Vite.

[View Portfolio](https://jaspe-portfolio.vercel.app)


## Local Setup

1. **Install dependencies:**

    ```bash
    npm install
    ```

2. **Run locally:**

    ```bash
    npm run dev
    ```

3. **Build for production:**

    ```bash
    npm run build
    ```
